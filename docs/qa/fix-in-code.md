# QA 12.10.2026 — что можно поправить кодом

Проверка прода https://hakaton.marshmeg.ru по критериям Положения (Приложения 1 и 2, п. 6.4).
ТЗ кейса выдают 15.10 — после него проверку нужно повторить.

## Средний приоритет
1. **Обрывы соединения.** Примерно 3 запроса из 11 к `hakaton.marshmeg.ru` закончились
   `connection reset` (к другим сайтам через тот же канал — без обрывов). Посмотреть логи Caddy и
   `web`, проверить таймауты и число воркеров. В WebView такой обрыв выглядит как экран «нет связи».
2. **Нет картинок и аудио.** В `seeds/content.yaml` ни одного `image:`/`audio:`. По ROADMAP это Must:
   картинки к словам и тип упражнения «послушай и выбери».

## Интерфейс (мелочи)
3. **Подпись урока на карте не кликабельна** — нажимается только кружок
   (`templates/learning/home.html`). Обернуть кружок и подпись в одну ссылку.
4. **Закрытый урок молчит при нажатии.** Показать подсказку «Сначала пройди предыдущий урок».
5. **Имя в шапке обрезается** на 360 px («Ива…»). Прятать имя на узких экранах и оставлять аватарку.
6. **Подсказки валидации форм — браузерные** («Please fill out this field» на телефоне с английским
   языком). Задать свои тексты (`setCustomValidity`) или полагаться на серверные ошибки Django.
7. **У ссылки урока нет `aria-label`** — внутри только «★»/«✓», экранный диктор не прочитает название.

## Работает — регрессий не нужно
- Вход, неверный пароль, регистрация (обязательные поля), выход.
- Карта курса, профиль, редактирование профиля, лидерборд, экран правил, страница 404.
- Урок: верно / неверно (−сердечко) / «Почти!» за ж з и о ч вместо Ӝ Ӟ Ӥ Ӧ Ӵ, сборка фразы, итог.
- 0 сердечек → «Начать заново»; диалог выхода; пустой ответ сердечко не тратит.
- Закрытый урок по прямой ссылке → редирект на карту; несуществующий урок → 404.
- Вёрстка 360 / 412 / 768 px без горизонтальной прокрутки, ошибок в консоли нет.
- Админка не пускает со стандартным паролем `admin/admin12345`.
